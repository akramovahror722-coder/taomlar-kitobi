# Taomlar Kitobi

O'zbek va jahon oshxonasidan 12 ta retsept: mahsulotlar, porsiya, qiyinchilik darajasi
va bosqichma-bosqich tayyorlash ko'rsatmalari.

## Imkoniyatlar

- 12 ta to'liq retsept, 7 kategoriya
- Qidiruv va kategoriya filtrlari
- Porsiya bo'yicha avtomatik hisoblash
- Sevimli retseptlar
- Tayyorlagan taomlar tarixi
- O'zbek, ingliz va rus tillari
- Yorug'/tun rejimi

## Texnologiyalar

React · TypeScript · Vite · Tailwind CSS · localStorage

## Ishga tushirish

```bash
npm install
npm run dev
```
